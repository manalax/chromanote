# PLAN

This app is built on top of the Lakebase starter template. It's a basic CRUD app-a todo application.

Here are the important files and directories:

- `./server/` -> backend
- `./server/routes/lakebase/` -> lakebase code
- `./client/` -> frontend
- `./databricks.yml` -> databricks configuration

## Features

You are going to build a knowledge-base note-taking application. It contains the following features:

- Time tracking
- Prioritization
- Tagging: creation of tags and tagging of notes
- Interconnected notes
- A working markdown editor and renderer. Preview should render markdown.
- Agent assistant with RAG, refer to RAG_TEMPLATE.md
- Ability to change the colour of the notes and fonts
- Ability to change the background colour of the app
- Image upload
- Dark and light mode
- Minimalist UI
